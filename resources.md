# Beginner Resources (Git & GitHub)

## Useful Learning Links
- Git Handbook (interactive): https://guides.github.com/introduction/git-handbook/
- GitHub Learning Lab: https://lab.github.com/
- Pro Git Book (free): https://git-scm.com/book/en/v2

## Beginner Checklist
- [ ] Understand `git status` before committing
- [ ] Practice `git add` + meaningful `git commit -m "message"`
- [ ] Create a feature branch for changes
- [ ] Open a pull request (PR) instead of editing `main` directly
- [ ] Review the PR changes before merging

## Tip
Commit small changes with clear messages so your history is easy to review later.
