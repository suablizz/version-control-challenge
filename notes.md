# Study Notes: Git & GitHub Basics

## What is Version Control?
Version control tracks changes to files over time so you can see what changed, when it changed, and who changed it.

## Key Git Commands
- `git status` — check what changed
- `git add <file>` — stage changes
- `git commit -m "message"` — save staged changes with a message
- `git log` — view commit history

## Branching (High Level)
A branch is a separate line of development. It’s useful for adding features or fixes without affecting the main code until you’re ready.

## Pull Requests (High Level)
A pull request (PR) is a request to merge changes from one branch into another (usually `main`). It supports review and discussion before merging.
